💡 Engineering Principles

* Readable code first: Prefer clarity over unnecessary cleverness.
* Reusable components: Build consistent UI without needless duplication.
* Separation of concerns: Keep UI, logic, and data responsibilities organized.
* Accessibility matters: Make interactions usable beyond mouse input.
* Root-cause debugging: Investigate before changing code.
* Minimal, focused fixes: Avoid unrelated refactoring and unintended side effects.
* Verification: Run relevant checks and validate the intended behavior.
